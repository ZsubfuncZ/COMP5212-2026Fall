      }

    \column{.52\textwidth}
      \textbf{The raw object is a customer}

      A customer generates events: visits, purchases, categories, returns, and time gaps.

      \vspace{.14cm}
      \textbf{The clustering input is a feature vector}
      \[
        x_i=(\text{recency},\text{frequency},\text{spend},\text{mix},\ldots).
      \]

      \vspace{.08cm}
      After suitable scaling, Euclidean distance describes which customers behave similarly.
