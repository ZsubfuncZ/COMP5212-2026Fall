# Trees and bagging after boosting: slide plan

Graduate machine-learning audience; approved Beamer template. This module follows the AdaBoost derivation and residual / gradient boosting. Nine frames, approximately 18–22 minutes. The decision-tree primer occupies only the first three frames; boosting does not require a preceding full tree lecture.

| Frame | Teaching point / evidence | Layout | Build | Speaker notes |
|---|---|---|---|---|
| 1. A tree predicts within regions | Recap the model used in earlier boosting illustrations; learned regions contain constant leaf predictions. Constructed depth-two regression tree. | Editable fitted step curve + leaf formula | Static | A stump is one split; multivariate trees form axis-aligned regions. |
| 2. Choose a split by reducing error | Greedy regression splitting minimizes child SSE. Exact six-point example. Brief classification aside: class frequencies and Gini impurity. | Equation + candidate table + compact aside | Static | Classification uses the same partition machinery with a different criterion; greedy is not globally optimal. |
| 3. Deep trees can be unstable | More capacity can overfit; resampling changes fitted trees. Existing computed validation curve and bootstrap prediction plot. | Two editable plots | Reveal averaging result | Capacity and sensitivity are related but different. One illustrative realization; bootstrap variability conditional on the original sample. |
| 4. Bagging averages bootstrap fits | Fit often-deep trees independently on samples with replacement, then aggregate. | Native flow diagram + mean / vote formula | Static | Bagging does not require every tree to be weak; distinguish its variance-reduction motivation from AdaBoost's weak-learning result. |
| 5. Why averaging can reduce variance | Equal variance and common pairwise correlation yield rho v + (1-rho)v/B at fixed input. | Three-line derivation | Two steps | Explain randomness and equal-covariance assumption; not an MSE guarantee. |
| 6. Correlation limits the benefit | Exact normalized variance curves illustrate correlation floor. | Native analytical plot + numerical cases | Static | More trees cannot remove bias or noise. |
| 7. Random forests vary each split | Bootstrap rows and draw a fresh candidate-feature subset at every node. | Native feature subset tree + algorithm | Static | Feature subsampling trades tree strength against correlation. |
| 8. Out-of-bag prediction | Use only trees whose bootstrap omitted a training row. Exclusion probability (1-1/n)^n tends to exp(-1). | Probability equation + row-ID table | Static | Optional if time is short; final evaluation must respect dependence and tuning. |
| 9. Two ways to build a stronger predictor | Contrast the boosting already covered with bagging and forests. | Side-by-side model-update / aggregation schematic | Static | Bagging often uses deep trees; no weak-learning theorem follows from averaging alone. |
