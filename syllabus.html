Course Description

This course covers core and recent machine learning algorithms. Topics include foundations of machine learning, supervised learning, unsupervised learning, deep learning, deep generative models, and reinforcement learning.

The foundations component covers learnability and complexity measures for learnable hypothesis classes. Supervised learning topics include linear regression, logistic regression, generative models for classification, and support vector machines. Unsupervised learning topics include K-Means, mixture models, and latent-variable models.

The course also introduces modern deep learning methods, including feedforward neural networks (FNNs), convolutional neural networks (CNNs), Transformers, and deep generative models, as well as reinforcement learning.

The course assumes that students have a solid grasp of probability, linear algebra, and Python programming. This is a math-intensive course. Assignments and the final project will require proficiency in probability, linear algebra, mathematical reasoning, and programming.

Course Objectives

Upon successful completion of this course, students will be able to:

  • Gain an overview of machine learning as a subject of study.
  • Understand the fundamental issues and principles in machine learning.
  • Understand core and recent machine learning algorithms.
  • Apply core and recent machine learning algorithms to solve real-world problems.

Topics

  • Foundations of Machine Learning: learnability and complexity measures for hypothesis classes
  • Supervised Learning: linear regression, logistic regression, generative models for classification, and support vector machines
  • Unsupervised Learning: K-Means, mixture models, and latent-variable models
  • Deep Learning: feedforward neural networks, convolutional neural networks, and Transformers
  • Deep Generative Models:VAE, GAN, and stable diffusion
  • Reinforcement Learning: reinforcement learning theory and deep reinforcement learning
