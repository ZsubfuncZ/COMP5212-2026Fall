Cardinality is not capacity

Thresholds and intervals both have infinitely many parameter choices. What matters first is the finite set of labelings they induce on the sample.

VC is worst-case combinatorics

VC dimension asks whether there exists a sample on which every labeling is available. One impossible pattern is enough to stop shattering.

Rademacher is sample-dependent

Rademacher complexity asks how much correlation the class can find in random signs on this particular sample. More flexibility means more ways to fit noise.

Teaching convention: the VC bound above uses a standard conservative form with illustrative constants; exact statements vary by loss class and assumptions. The 1D Rademacher panel uses ±1 predictions, so the memorization class reaches 1 exactly.
